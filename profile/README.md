## 👋 关于我们 | About Us

> **比特（bit）** 是计算最小的信仰，  
> **火炬** 是让想法不再停在脑子里的那团火。

**中文**  
比特火炬（`bit-torch`）是一支由开发者组成的开源轻骑兵。我们从网络底层（Easytier, Rust）出发，向上生长出实用的工具（CrossBag, AdapterGit），并最终点亮面向用户的智能体验（MusKitty, HalloChat）。

**EN**  
BitTorch (`bit-torch`) is a cavalry of open-source developers. We start from the network layer (Easytier, Rust), grow practical tools (CrossBag, AdapterGit), and ultimately light up user-facing intelligent experiences (MusKitty, HalloChat).

## 🌟 组织特色 | Our Philosophy

- **🦀 拥抱 Rust | Embrace Rust**  
  核心基建与高性能服务主要采用 Rust 构建，追求极致的性能与安全。  
  *Core infrastructure and high-performance services are primarily built with Rust, pursuing ultimate performance and safety.*

- **🔗 连接一切 | Connect Everything**  
  从内网穿透、文件同步到即时通讯，致力于打破数字壁垒。  
  *From NAT traversal and file syncing to instant messaging, dedicated to breaking down digital barriers.*

- **🧩 全栈视野 | Full-Stack Vision**  
  仓库涵盖了从底层网络、后端服务、前端应用到 DevOps 运维的完整技术栈。  
  *Repositories cover the full stack from low-level networking and backend services to frontend apps and DevOps.*
